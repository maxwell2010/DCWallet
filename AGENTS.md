# Project instructions

- In descriptions, documentation and other user-facing text, use short hyphens (`-`) instead of long dashes. Preserve code syntax, literal source quotations and third-party license text.
- Never commit wallet files, recovery phrases, private keys, local environment files or network-test recovery artifacts. Generated builds and test reports belong in ignored `artifacts/`.
- A transaction builder or fixture test does not establish deployed contract compatibility. Keep public capability and validation claims aligned with recorded evidence.
