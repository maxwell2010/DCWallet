# DC WALLET 0.2.0

Публичный стабильный desktop-релиз для Windows, Linux и macOS, x64 и ARM64. [Скачать актуальную версию](https://github.com/maxwell2010/DCWallet/releases/latest). Номер версии не входит в постоянные ссылки README.

## Возможности

BIP39 12/24 слова, импорт приватного ключа, независимые зашифрованные профили, резервные копии, режим просмотра, три темы, автоматическая загрузка DEL/ERC20/NFT/стейков, история и проверка квитанций. Переводы и рассылка CSV/XLSX, обмен DEL/токен и токен/токен, делегирование и завершение отзыва, взвешенные Decimal Safe и чеки поддерживаются в пределах опубликованной матрицы.

При запуске выполняется одна проверка стабильной версии GitHub. Только новая версия вызывает небольшое окно с текущим и доступным номерами. «Обновить» открывает скачивание для платформы; файлы приложения автоматически не заменяются. Актуальная версия и недоступная сеть не вызывают уведомлений. Запрос версии не содержит адресов, балансов и секретов кошелька. Зеркало alpha позволяет ранее установленным alpha-клиентам увидеть стабильную 0.2.0.

При блокировке очищаются кэши активов и истории. Повторный вход и подключение другого RPC той же сети не показывают старый баланс как свежее подтверждение. Журнал отправки сохраняется атомарно до передачи транзакции в RPC; ошибка записи останавливает отправку.

## Проверки и происхождение файлов

Публикация разрешена только из успешного [Native checks](https://github.com/maxwell2010/DCWallet/actions/workflows/check.yml). Все шесть нативных платформ выполняют Core/UI-тесты, проверяют фактическую архитектуру процесса, запускают конечные бинарные файлы и проверяют пакеты. Общий этап проверяет полный комплект и SHA-256. Известные уязвимости прямых и транзитивных NuGet-зависимостей проверяются в CI с блокировкой ошибок аудита.

Точные run ID и commit SHA добавляются издателем в описание релиза. Они являются доказательством прогона конкретной сборки. Исходники фиксируются тегами `v0.2.0` и `build/0.2.0`; файлы берутся из проверенного артефакта без пересборки. DOWNLOADS.json содержит версию и соответствие 13 постоянных и 13 версионных файлов, SHA256SUMS.txt содержит контрольные суммы.

Ранее подтверждены 29 testnet-транзакций с каноническими квитанциями и проверкой итогового состояния, pending 0. Пять локальных fork-проверок покрыли срок чеков, роли, создание резервного токена и hold/time travel. Перед выпуском два readonly-теста повторно сверили все 29 канонических квитанций и итоговые состояния, pending 0. Новых транзакций при этой проверке не отправлялось. [Отчет выпуска](https://github.com/maxwell2010/DCWallet/blob/main/docs/RELEASE-VALIDATION-0.2.0.md). Подпись и отправка mainnet-транзакций в рамках выпуска не выполняются.

## Границы релиза

Мост исключен по указанию пользователя. Mainnet NFT-делегирование ограничено внешней паузой registry-контракта; сообщение и проверка до нового approval/делегирования сохраняются. Подмена testnet ABI и попытка unpause не выполняются.

Редкие ABI/role-комбинации и глобальные административные операции сети не объявляются сертифицированными. Каталог 118 builders не означает реализацию всех возможных административных методов. Независимый аудит безопасности не проводился; Windows без сертификата подписи, macOS без Developer ID/notarization. Публикация stable обозначает принятый объем потребительского кошелька и не является сертификацией.
