# DC WALLET 0.2.3

Обновление истории для Windows, Linux и macOS, x64 и ARM64. [Скачать актуальную версию](https://github.com/maxwell2010/DCWallet/releases/latest). Постоянные ссылки в README сохраняются.

## История

Полная контрольная история из 64 операций загружена двумя страницами 50+14. 30 записей подтверждены RPC, 34 сохранены как архивные, ошибок чтения 0. Ранее эти 34 записи ошибочно учитывались как ошибки проверки: подключенные узлы не хранят их старые блоки, транзакции и квитанции. Архивные записи сохраняют точные суммы и отметку источника, не объявляются RPC-проверенными.

Добавлены раздельные счетчики подтвержденных/архивных записей и ошибок, диагностические причины по каждому хешу, verification_reason в CSV. Реальное несовпадение квитанции или поврежденная запись по-прежнему считается ошибкой и имеет отдельную отметку в истории. Исправлен двойной учет поврежденной архивной строки.

Уточнение к предыдущему расследованию: пустые ответы относились к другому адресу, ошибочно переписанному со скриншота с одной заменой символа. Для правильного адреса API возвращает 64 записи. [Подробный отчет](https://github.com/maxwell2010/DCWallet/blob/main/docs/HISTORY-AUDIT-0.2.3.md).

## Проверки и происхождение файлов

Выпуск публикуется только после успешного Native checks: шесть платформ, Core/UI-тесты, аудит зависимостей, нативная архитектура, self-test бинарных файлов и пакетов, полный комплект и SHA-256. Используются проверенные артефакты без пересборки. Источник фиксируется тегами v0.2.3 и build/0.2.3; run ID и source SHA добавляются издателем.

Для RPC-проверки всех 34 старых операций нужен архивный узел с блоками до 28325675. Проверенные публичные и собственные ноды этот диапазон не предоставили. Новые сетевые транзакции в рамках этого обновления не отправлялись. Исторический [testnet-прогон](https://github.com/maxwell2010/DCWallet/blob/main/docs/NETWORK-VALIDATION-0.2.1.md) остается отдельным свидетельством предыдущей версии.

## Границы релиза

Мост исключен. Mainnet NFT-стейкинг сохраняет сообщение о паузе. Ограничения [матрицы возможностей](https://github.com/maxwell2010/DCWallet/blob/main/docs/CAPABILITIES.md) сохраняются. Windows и macOS пока без доверенных сертификатов подписи, macOS без notarization. Независимый аудит безопасности не проводился.
