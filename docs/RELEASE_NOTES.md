# DC WALLET 0.2.1

Обновление для Windows, Linux и macOS, x64 и ARM64. [Скачать актуальную версию](https://github.com/maxwell2010/DCWallet/releases/latest). Постоянные ссылки в README сохраняются при обновлении.

## Что изменилось

- Исправлено чтение стейков после обновления Decimal от 29-30.10.2026. Поддерживаются старые структуры из 7 полей и новые из 8 полей для отдельных стейков, hold-позиций и замороженных заявок.
- Новое поле holdStartTime хранит начало hold отдельно от суммы и окончания hold. При наличии оно отображается в карточке позиции. Расчет количества токенов и срока разморозки сохранен.
- Формат ответа проверяется при каждом чтении, включая исторические блоки. Перезапуск приложения после смены ABI не требуется. Неизвестный формат или поврежденный ответ вызывает ошибку проверки позиции и отметку неполноты данных; недоступный стейк не подменяется нулем.
- Windows запрашивает согласие перед первой проверкой обновлений GitHub. Выбор можно изменить в настройках. В подготовленных Store-сборках внешний механизм обновлений отключен.
- Добавлена MIT-лицензия оригинального кода с сохранением лицензий сторонних компонентов.

Проверка новой версии выполняется один раз при запуске, если разрешена. Только новая версия вызывает окно с текущим и доступным номерами. Кнопка обновления открывает скачивание для платформы; файлы приложения автоматически не заменяются. Актуальная версия и недоступная сеть не вызывают уведомлений. Зеркало alpha сохраняет совместимость с ранними alpha-клиентами.

## Проверки

Публикация разрешена только из успешного [Native checks](https://github.com/maxwell2010/DCWallet/actions/workflows/check.yml): шесть платформ, Core/UI-тесты, фактическая архитектура процесса, self-test опубликованных бинарных файлов и пакетов, проверка полного комплекта и SHA-256, аудит NuGet-зависимостей. Точные run ID и commit SHA добавляются издателем в описание релиза. Файлы берутся из проверенного артефакта без пересборки и фиксируются тегами v0.2.1 и build/0.2.1.

Добавлены 14 регрессионных случаев для обоих ABI, токенов и NFT, сумм и hold, замороженных заявок, некорректных ответов и смены формата без пересоздания reader. Локально: 361 Core-тест и 40 UI-тестов прошли; 23 сетевых/fork-теста требуют отдельного явного включения и пропущены в обычном прогоне.

Два публичных mainnet RPC подтвердили ответ getStake из 8 полей на блоке 34349868. Проверка использовала пустые публичные координаты и подтверждает формат ответа, а не жизненный цикл заполненного NFT/hold. Новые транзакции не подписывались и не отправлялись. [Подробный отчет совместимости](https://github.com/maxwell2010/DCWallet/blob/main/docs/DECIMAL-STAKE-ABI-2026-10-30.md). Исторические сетевые проверки предыдущего выпуска описаны [отдельно](https://github.com/maxwell2010/DCWallet/blob/main/docs/RELEASE-VALIDATION-0.2.0.md) и не выдаются за повторный прогон этой версии.

## Границы релиза

Мост исключен. Mainnet NFT-делегирование сохраняет проверку паузы контракта и сообщение пользователю. Редкие ABI/role-комбинации и административные операции сети не объявляются сертифицированными; [матрица возможностей](https://github.com/maxwell2010/DCWallet/blob/main/docs/CAPABILITIES.md) остается применимой.

Windows и macOS пока без доверенных сертификатов подписи; macOS без notarization. SignPath Foundation отклонила бесплатную заявку из-за недостаточной публичной известности проекта. MSIX остается подготовкой для будущего Store-размещения и не входит в этот публичный комплект. Независимый аудит безопасности не проводился.
