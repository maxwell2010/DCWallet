# DC WALLET 0.2.4

Десктопное обновление для Windows, Linux и macOS, x64 и ARM64. [Скачать актуальную версию](https://github.com/maxwell2010/DCWallet/releases/latest). Постоянные ссылки в README сохраняются.

## Парольная защита

В настройках можно отключить пароль текущего профиля, включая вход и подписи транзакций/Permit. Требуются текущий пароль и явное подтверждение предупреждения. Подтверждение параметров и отправки остается обязательным. Защиту можно включить обратно с новым паролем от 12 символов.

Важно: в режиме без пароля любой с доступом к файлу кошелька сможет получить ключи и распоряжаться средствами. Автоблокировка не заменяет пароль. Сделанные в этом режиме копии остаются доступными без пароля даже после повторного включения защиты. Режим по умолчанию выключен, существующие кошельки автоматически не меняются. [Описание](https://github.com/maxwell2010/DCWallet/blob/main/docs/PASSWORD-PROTECTION.md).

## Permit в десктопных формах

Делегирование ERC20, HOLD и обмен токен-токен получили отдельное согласие на локальную EIP-712 подпись, затем отдельное подтверждение транзакции и комиссии. Новый путь включен только в проверенном Decimal Testnet-профиле chainId 202020. Mainnet сохраняет прежний режим явных разрешений. При достаточном allowance остается обычный вызов; ненулевой недостаточный allowance требует явного revoke. Автоматического approve нет.

Повторно проверяются пины контрактов, домен, nonce, deadline, баланс, allowance, поля формы и minimumOut. Блокировка/навигация/деактивация отменяют подготовку. Реальный Avalonia Headless UI-прогон с настоящими RPC и подписью подтвердил три Testnet-транзакции: delegateByPermit, delegateHoldByPermit и Permit convert. Это проверка десктопных форм, не установленного приложения на всех ОС. [Отчет](https://github.com/maxwell2010/DCWallet/blob/main/docs/DESKTOP-PERMIT-TESTNET-2026-10-31.md).

## Проверки и границы

Релиз публикуется из проверенных артефактов успешного Native checks без пересборки. Шесть платформ проходят Core/UI-тесты, аудит зависимостей, проверку архитектуры, self-test и проверку пакетов/полного комплекта/SHA-256. Run ID и source SHA добавляются издателем. Opt-in сетевые тесты в обычной CI не отправляют транзакции автоматически; их пропуски не объявляются сетевыми успехами.

Мост исключен. Mainnet NFT-стейкинг сохраняет сообщение о паузе. Windows и macOS пока без доверенных сертификатов подписи, macOS без notarization. Независимый аудит безопасности не проводился. Android в этот выпуск не входит.
