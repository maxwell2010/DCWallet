# DC WALLET 0.2.2

Обновление интерфейса и загрузки данных для Windows, Linux и macOS, x64 и ARM64. [Скачать актуальную версию](https://github.com/maxwell2010/DCWallet/releases/latest). Постоянные ссылки в README сохраняются.

## Что изменилось

- Убрана дублирующая вкладка «Инструменты». Расширенные формы открываются внутри соответствующих разделов: токены, NFT, обмен и стейкинг.
- «Мост» открывает собственный экран с текущим статусом. Непроверенные отправки и завершение межсетевых переводов отключены.
- В «Отправить» доступны обычный перевод, рассылка и сжигание. Чеки остаются в левом меню. Сжигание требует явного подтверждения необратимости, проверки суммы и отдельного просмотра операции перед подписью.
- Под выбранным кошельком отображается адрес без технических меток «фраза» или «ключ». Нажатие копирует полный адрес, наведение показывает его полностью.
- Исправлено постоянное предупреждение об источниках: обычная задержка NFT-индекса и ограничение охвата внешних коллекций отделены от ошибок соединения. Свежий полностью пройденный индекс Decimal дополняет устаревшую резервную очередь разморозки. Настоящие сбои чтения, большой лаг индекса, неверный ABI и непроверенные балансы сохраняют соответствующую диагностику.
- История отображается без общего технического предупреждения и счетчика ошибок. Архивные неподтвержденные записи имеют нейтральную отметку «Данные архива» с пояснением по наведению. Метки источника и проверки сохраняются в CSV.
- Исправлен выбор RPC для истории: удачное чтение старой квитанции из архива больше не отключает основной RPC для новых операций. Временная ошибка подключения к архиву не кэшируется навсегда. Параллельная проверка истории снижена до трех операций.

## Проверки

Нативный выпуск разрешен только из успешного [Native checks](https://github.com/maxwell2010/DCWallet/actions/workflows/check.yml). Шесть платформ выполняют Core/UI-тесты, проверку архитектуры, self-test конечных бинарных файлов и пакетов, аудит зависимостей и проверку полного набора SHA-256. Файлы публикуются из проверенного артефакта без пересборки; источник фиксируется тегами v0.2.2 и build/0.2.2. Точные run ID и source SHA добавляются издателем.

Регрессии проверяют восстановление основного RPC после отстающего архива, повторное подключение к архиву, свежие и устаревшие источники стейкинга, обычный и большой лаг NFT-индекса, копирование адреса, отсутствие дублирующих маршрутов, необратимость сжигания и различие архивных/подтвержденных записей. Экраны проверены в трех темах.

Readonly-проверка живых источников для публичного адреса пользователя на блоке 34350752 подтвердила отсутствие ошибок загрузки NFT/стейкинга. Все проверенные HTTP endpoint отвечали 200; резервный withdrawal-кэш при этом был устаревшим и заменен свежим индексом. Это не гарантия полноты всех внешних NFT-коллекций. Наблюдавшиеся ранее 34 ошибки истории по текущим API повторно не воспроизведены: они вернули пустую историю. Исправление переключения RPC подтверждено отдельными регрессионными тестами и не выдается за проверку всех 34 старых записей.

Сетевые транзакции при подготовке этого обновления не выполнялись. Отдельный [прогон 0.2.1](https://github.com/maxwell2010/DCWallet/blob/main/docs/NETWORK-VALIDATION-0.2.1.md) подтвердил 18 применимых opt-in тестов, 22 новые testnet-транзакции и pending 0. Это исторический отчет предыдущей версии, а не повторная отправка из 0.2.2.

## Границы релиза

Мост исключен. Mainnet NFT-делегирование сохраняет проверку паузы контракта. Ограничения [матрицы возможностей](https://github.com/maxwell2010/DCWallet/blob/main/docs/CAPABILITIES.md) сохраняются.

Windows и macOS пока без доверенных сертификатов подписи; macOS без notarization. Подготовленные MSIX не означают размещение в Microsoft Store и не входят в публичный комплект. Независимый аудит безопасности не проводился.
