## Сборки и ограничения

Собираются Windows/Linux/macOS x64/ARM64 с SHA-256. Windows x64 проходит self-test готового файла. Остальные сборки требуют нативного прогона на соответствующих ОС. GitHub Actions не запускался, внешняя публикация не выполнялась.

Полная готовность всех сетевых сценариев пока не подтверждена: NFT staking testnet требует миграции ABI ([исследование](TESTNET-NFT-ABI.md)); его индексатор возвращает только старые записи. Журнал и известные хэши сверяются через RPC. Для Safe, checks, bridge, специфичных NFT/validator/permit методов остаются отдельные сетевые сценарии и необходимые тестовые развертывания. Статус alpha сохраняется.
