# DC WALLET 0.2.0-alpha.2 - проверка обновления

Дата: 29.10.2026. Windows/Linux/macOS x64/ARM64 собраны отдельно. Windows x64 проходит self-test готового файла; остальные платформы требуют нативного прогона.

## Изменения интерфейса

- Обмен DEL/токен и токен/токен. Convert получает обе котировки на одном блоке, учитывает проскальзывание и требует только точного разрешения. Buy/sell лишнего approve не требуют.
- Рассылка: импорт CSV/TSV/XLSX, предпросмотр и добавление/замена строк, экспорт CSV/XLSX. До 500 строк и 256КБ. XLSX сохраняет суммы текстом, включая 18 знаков; точность отдельно подтверждена openpyxl.
- Компактные суммы и точные значения при наведении. Ввод, расчеты, подпись и экспорт не округляются.
- Оценка резервного токена в DEL по котировке продажи всего баланса на закрепленном блоке, без комиссии. При отсутствии котировки показано явное сообщение.
- Инструменты: быстрые обычные действия, описания и подсказки. Контракты и JSON скрыты в расширенных параметрах. Исправлен захват JsonElement из закрытого документа.

## Автоматические проверки

251 core + 27 Avalonia Headless тестов прошли, без предупреждений. 7 сетевых opt-in проверок помечаются skipped в обычном прогоне и запускаются отдельно. Каталог SDK остается118 методов; его полный fixture-прогон не означает успешного исполнения всех методов в сети.

## Мост и оставшиеся границы

По указанию пользователя мост пропущен после проверки актуального go-smart-node/master9e6c6d7: адресов bridge-v2, маршрутов второго плеча и VM-сервиса нет. Депозитов не делали. Подробности: [TESTNET-BRIDGE-DISCOVERY.md](TESTNET-BRIDGE-DISCOVERY.md).

Статус остается alpha. Не подтверждаются этим прогоном все NFT721/hold/permit варианты, Safe EIP-1271/delegatecall, токеновые чеки, реальный convert и управление производственными валидаторами. Testnet-индексаторы могут отставать; используются RPC-проверки известных позиций/журнала. Нативные Linux/macOS/ARM64 тесты и внешний аудит отдельные.

Финальный независимый RPC-аудит: 2 теста прошли. Все 13 receipt и внутренних Safe execution проверены; 13 журналов confirmed, pending 0. Повторное погашение чека отклонено без отправки. Сборка Windows x64: ProductVersion 0.2.0-alpha.2, self-test exit 0. SHA256 всех 6 файлов проверен; 43 файла SDK совпадают с SOURCE.json.
