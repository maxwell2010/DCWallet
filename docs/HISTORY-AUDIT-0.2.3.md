# История DC WALLET 0.2.3 - проверка 30.10.2026

## Причина пустого ответа

При предыдущем исследовании адрес со скриншота был переписан с ошибкой: в конце `...008cbc615249a` вместо `...008cb0615249a`. Это два разных EVM-адреса. Для ошибочного адреса три RPC возвращали nonce 0 и баланс 0, а API - пустую историю. Это была ошибка исследовательского запроса, а не доказательство потери истории кошельком.

Правильный публичный адрес установлен по имени локального discovery-кэша кошелька. Для него подтверждены chain ID 75, nonce 39 и ненулевой баланс. Официальный API вернул count 64: 50 записей с offset 0 и 14 с offset 50, все хеши уникальны. Персональный список операций и полные адреса в этом публичном отчете не публикуются.

## Почему было 34 ошибки

На исходном коде 0.2.2 результат воспроизведен точно: 64 записи загружены, 30 проверены RPC, Failed = 34. Все 34 относятся к блокам 28325675-30432865, датам 06.10.2025-19.02.2026. Для каждого из этих хешей основной и резервный RPC вернули отсутствие транзакции и квитанции, а не отрицательный статус исполнения.

Дополнительно проверены границы хранения через CometBFT status:

| Узел | Самый ранний доступный блок |
| --- | ---: |
| node.decimalchain.com | 30894001 |
| node4-mainnet.decimalchain.com | 30894001 |
| node1-mainnet.decimalchain.com | 34086001 |
| node2-mainnet.decimalchain.com | 33870001 |
| node1.mintcandy.ru | 33286001 |
| node2.mintcandy.ru | 34271001 |
| maxmoda.mintcandy.ru | 33505001 |

Для контрольного старого блока 30432865 основной CometBFT RPC явно ответил: height is not available, lowest height is 30894001. Для контрольного старого Cosmos tx hash возвращен tx not found. Thirdweb также не вернул старые EVM-транзакцию, квитанцию и блок. node3-mainnet не ответил за отведенный timeout. Проверены источники, упомянутые в чате MintCandy Explorer; найденный там архив транзакционных записей не является архивным EVM RPC.

Это снимок доступности на 30.10.2026, не постоянная характеристика всех возможных нод. Повторная RPC-верификация этих 34 записей требует настоящего архивного узла с блоками как минимум до 28325675. Индексаторные суммы и статусы не объявлены RPC-подтвержденными.

## Изменения

- Введены раздельные счетчики Verified, Archived и Failed. Отсутствие исторических RPC-данных учитывается как архивная доступность, а не повреждение записи или доказательство неуспешной транзакции.
- Для каждого хеша сохраняются диагностические результаты основных/архивных чтений: missing transaction/receipt/block, несовпадение квитанции, другая сеть или транспортная ошибка. Сырые RPC-ошибки и секреты подключения не экспортируются.
- Все архивные операции сохраняются в истории с исходными точными суммами и отметкой indexer-evm. Неудачная настоящая проверка имеет отдельную отметку «Проверка не пройдена».
- CSV сохраняет verification и дополнительно verification_reason.
- Исправлен двойной учет ошибки, когда отсутствующая RPC-квитанция сочеталась с поврежденной архивной записью.

## Подтверждение

На живых данных после изменения: Rows = Total = 64, Complete = true, Verified = 30, Archived = 34, Failed = 0. Для всех 34 архивных строк сохранен archive_unavailable; оба RPC сообщили transaction_and_receipt_missing. Это полная загрузка каталога, а не полная RPC-верификация всех операций.

Регрессионные проверки покрывают две страницы 50+14, сохранение всех 64 записей, точные счетчики и CSV, неподходящую identity квитанции, транспортный сбой архивного RPC и поврежденную архивную запись. Настоящие ошибки продолжают учитываться, проверки hash/block/sender/status не отключались. UI дополнительно проверяет отдельную отметку для verification_failed в трех темах.

Сырые ответы, 64 записи, CSV и диагностика хранятся только локально в игнорируемой artifacts/history-audit-20261030. Ключи, seed-фразы, файл кошелька и профиль подписанта не читались; блокчейн-транзакции не создавались и не отправлялись.
