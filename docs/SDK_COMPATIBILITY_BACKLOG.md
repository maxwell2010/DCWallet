# C# release backlog - 2026-10-29

The C# package is a standalone Decimal SDK. Official [JS SDK](https://bitbucket.org/decimalteam/dsc-js-sdk/src/master/) `6790d35`, [Go SDK](https://bitbucket.org/decimalteam/dsc-go-sdk/src/master/) `3ef4a08`, and [go-smart-node](https://bitbucket.org/decimalteam/go-smart-node/src/master/) `9e6c6d7` snapshots are protocol evidence, not APIs to copy method for method. The JS `decimalevm/index.ts` has 158 async public methods, including reads and helpers; the Go `decimalevm/methods` directory has 58 exported operations. These are not comparable transaction-type counts. Deployed testnet ABI may differ from the current node ABI, as confirmed for NFT creation and frozen stakes.
