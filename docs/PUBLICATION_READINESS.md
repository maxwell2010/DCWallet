# Готовность к публикации - 29.10.2026

Публичный исходный репозиторий и нативные Actions проверки разрешены пользователем 29.10.2026. Публичный бинарный релиз этим шагом не публикуется. Мост исключен из текущего объема. Текущая локальная сборка 0.2.0-alpha.3.

## Что закрыто этим этапом

Импорт приватного ключа и независимые профили; backward-compatible vault; Safe contract signatures/DelegateCall/weighted routing; полноценный обменный файл чеков и allowance/permit циклы; токен-токен обмен с обоими видами разрешения; ERC721 и резервный ERC20 delegate/withdraw/complete; актуальные NFT native-reserve selectors/фабрики; динамическая комиссия создания токена и новый TokenDeployed receipt.

29 новых публичных testnet-транзакций независимо подтверждены, pending0. Исходные активы и разрешения восстановлены, NFT возвращен владельцу, обе заявки завершены. Mainnet проверки были readonly. Точные результаты: [VALIDATION-COMPLETION.md](VALIDATION-COMPLETION.md).

Каталог 118 builders проверен отдельными ABI-срезами и fixtures, но его размер не означает 118 уникальных типов или проверку всех параметров/ролей в публичной сети. Глобальные privileged governance/upgrade методы контрактов явно исключены из обычного wallet scope; отсутствующие административные формы не объявляются реализованными. [Матрица возможностей](CAPABILITIES.md).

## Что остается перед публичным релизом

- Mainnet NFT-делегирование сейчас ограничено внешней паузой registry delegation-nft: paused=true подтвержден прямым RPC, delegate preflight возвращает EnforcedPause. Положительный сетевой прогон после снятия паузы требует действий сопровождающих сети. Приложение не запрашивает их ключи и не пытается unpause. Это не исправляется сменой адреса на testnet combined.

- Нативные запуски и упаковка Linux/macOS/ARM64 на соответствующих runners. В этой среде проверен Windows x64; WSL-дистрибутивов и работающего Docker Linux Engine нет. Шесть cross-build файлов не заменяют нативный CI.
- Проверка публичных заявлений по итоговым CI и матрице: редкие NFT/hold/permit комбинации и все административные role-ветки не сертифицированы текущим live-прогоном.
- Выбор лицензии собственных исходников и оформление репозитория. Лицензия SDK и атрибуция предоставленных пользователем ресурсов сохранены.
- Повторная проверка фактического Git index и отправляемой истории на секреты непосредственно перед первым push. `.env`, private keys, vault и artifacts исключены из Git.

Репозиторий: [maxwell2010/DCWallet](https://github.com/maxwell2010/DCWallet). Нативные результаты доступны в [Actions](https://github.com/maxwell2010/DCWallet/actions/workflows/check.yml). [Постоянные имена релизов](RELEASE_DOWNLOADS.md) подготовлены, но GitHub latest-ссылки начнут работать только после опубликованного stable release. Draft/prerelease туда не попадает.

Независимый security audit и сертификаты подписи приложений не выполнялись. Это не результат тестирования и не заявление о сертификации. Сборка остается alpha.
