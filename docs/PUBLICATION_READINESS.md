# Готовность к релизу 0.2.0 - 29.10.2026

Пользователь разрешил публичный стабильный релиз в пределах обычных функций desktop-кошелька. Мост исключен. Внешняя пауза mainnet NFT-делегирования остается принятым ограничением и показывается до подготовки нового разрешения или делегирования. Стабильный статус не требует обхода этой паузы.

## Объем

Ключи и независимые зашифрованные профили, активы и история, DEL/ERC20/NFT, рассылка и таблицы, обмен, стейкинг и заявки, Safe и чеки описаны в [CAPABILITIES.md](CAPABILITIES.md). Наличие 118 SDK builders не считается подтверждением всех возможных развернутых контрактов, параметров или административных ролей.

Исторические testnet-проверки, 29 новых подтвержденных транзакций, итоговые состояния и локальные fork-проверки сохранены в [VALIDATION-COMPLETION.md](VALIDATION-COMPLETION.md) и [LOCAL-FORK-VALIDATION.md](LOCAL-FORK-VALIDATION.md). Они не переименовываются в новый сетевой прогон stable. Новые CI-задания не получают seed-фраз и не отправляют публичные транзакции.

## Условия публикации

- Выбранный прогон Native checks должен успешно завершить шесть нативных платформ и общий этап комплектности файлов. Выполняются Core/UI-тесты, проверка архитектуры и конечных бинарных файлов, распаковка и запуск пакетов.
- Аудит прямых и транзитивных NuGet-зависимостей включен; предупреждения об известных уязвимостях блокируют сборку.
- Публикация получает проверенный артефакт выбранного run ID без пересборки. Хэши сверяются перед открытием релиза. Run ID и commit SHA записываются в описание.
- `v0.2.0` публикуется как неизменяемый stable/Latest; `build/0.2.0` сохраняет тот же коммит. Alpha-зеркало поддерживает обновление ранее установленных клиентов.
- Vault, seed, private keys, .env, тестовые recovery-артефакты, bin/obj и результаты сборок исключены из Git. Вендорный SDK сохраняет byte-exact SHA-256 из SOURCE.json.

Конфигурация CI сама по себе не означает успешный прогон. Текущий результат доступен в [Actions](https://github.com/maxwell2010/DCWallet/actions/workflows/check.yml); точные результаты этой публикации фиксируются издателем. До выполнения условий новая stable-публикация не считается завершенной.

## Сохраненные ограничения

Mainnet NFT-пауза требует действий сопровождающих сети и отдельного положительного прогона после снятия паузы. Token/DEL delegation не объявляется приостановленным из-за NFT-контракта. Мост отложен; governance/upgrade, consensus node и подписи чужих администраторов не входят в потребительский объем.

Независимый аудит безопасности и сертификаты подписи приложений отсутствуют; macOS notarization не настроена. Эти ограничения указаны в README и release notes. Оригинальный код и документация теперь распространяются по MIT из корневого LICENSE; лицензии SDK и атрибуция сторонних ресурсов сохранены. Добавление MIT не означает получения сертификата или одобрения SignPath/Store. Опубликованные файлы 0.2.0 не заменялись.
