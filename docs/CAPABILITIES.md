# DC WALLET 0.2.0

Каталог C# SDK содержит 118 методов TransactionDraft/Task<TransactionDraft>, включая перегрузки. Это не 118 уникальных типов сети и не перечень всех административных методов контрактов. Кошелек использует deployment-aware адаптеры и отдельные формы там, где старый SDK не соответствует развернутому Decimal ABI.

| Область | Реализовано | Проверки и границы |
| --- | --- | --- |
| Ключи | BIP39 12/24 слова, независимые профили, импорт приватного ключа, typed encrypted vault, резервная копия, блокировка/смена пароля | Legacy BIP39 v1 совместим; private-key v2 дает один адрес, seed -10 адресов. Аппаратные и мобильные кошельки не входят в этот desktop-проект |
| Активы | Автозагрузка DEL/ERC20/NFT/стейков, закрепленный блок, RPC ownership/balance, отмена при смене профиля/сети, периодическое обновление | Каталоги дают кандидатов, отсутствующие источники отмечаются как неполный охват |
| Токены | Перевод, approve/transferFrom, decimals и точные суммы, компактный вывод и exact tooltip, резервная оценка в DEL, создание/выпуск/сжигание/параметры через формы | Комиссия создания читается из Token Center; резерв задается отдельно и проверяется контрактом. Non-mintable cap0, актуальный tuple TokenDeployed поддерживается |
| Рассылка | DEL/ERC20, CSV/TSV/XLSX импорт, CSV/XLSX экспорт, предпросмотр,500 строк/256 КБ, точный approve/permit | Совместимость permit проверяется по domain/nonce; DEL aggregate в testnet задается явно |
| Обмен | DEL/токен и токен/токен, exact input/output SDK формы, котировка/проскальзывание, точный approve/permit | Реальные A-B-DEL циклы с allowance и permit подтвердили балансы, события и minimum output |
| NFT | ERC721/1155, поиск/страницы, передача, создание/выпуск/резерв/сжигание через формы, проверка владельца | Проверенные фабрики обеих сетей используют legacy DRC tuple6. Для native reserve выбирается ETH или DEL selector только после успешной симуляции; неизвестные ABI не объявляются совместимыми |
| Стейкинг | DEL/ERC20/NFT, hold, валидаторы, отзыв/перенос/сброс hold, frozen completion | ERC1155 предыдущего этапа и ERC721/резервный ERC20 этого этапа прошли реальные delegate/withdraw/complete. DEL hold/reset проверен на локальном fork. Редкие NFT permit/hold комбинации требуют совместимого контракта и успешной симуляции |
| Валидаторы |13 собственных SDK management builders, имена и адреса, роли проверяются исполнением/симуляцией | Все 13 selectors совпали с первичным ABI; полный публичный role-прогон не выполнен. Пять глобальных governance методов MasterValidator не входят в обычные функции кошелька |
| Decimal Safe | Взвешенные владельцы, создание, предложения, EOA/approved_hash/contract signatures, Call/DelegateCall, on-chain hash/nonce, симуляция и внутреннее событие успеха | Реально проверены 2+1/порог 3 и контракт-владелец с Call/DelegateCall. Старые generic SDK Safe builders скрыты: getThreshold/count-quorum/approveHash(bytes32) несовместимы с Decimal weighted Safe |
| Чеки | Зашифрованный bearer-файл, DEL/ERC20/permit, свежий creator nonce, предсказанный hash, receipt activation, погашение/replay | Testnet DEL и токеновые циклы проверены; mainnet direct runtime и create eth_call проверены без mainnet отправки. Expiry проверен на fork |
| История | Все страницы доступного mainnet-каталога, канонические receipts/комиссии, DEL/ERC20/ERC721/1155 movements, memo/поиск/CSV, журнал и ручной hash, распознавание ABI-намерений и отдельный внутренний результат Safe | Indexer-only строки явно отличаются от RPC-проверенных. Доступность/полнота каталога не гарантируется приложением |
| Интерфейс | Светлая/темная/Криптопанк/системная тема, подсказки, расширенные параметры, сохранение форм при обновлении, профили и контраст | Native Avalonia, headless проверки трех тем. Шесть нативных платформ проходят Core/UI-тесты, проверку архитектуры, финальных файлов и пакетов в Native checks; run ID фиксируется в релизе |
| Мост | SDK draft-формы сохранены | Исключен из текущего объема по указанию пользователя |

Фактические тесты и 29 новых testnet-транзакций: [VALIDATION-COMPLETION.md](VALIDATION-COMPLETION.md). Полная матрица 118 builders: [TRANSACTION-MATRIX.md](TRANSACTION-MATRIX.md). Независимые срезы: [токены/чеки](ABI-TOKENS-CHECKS-AUDIT.md), [NFT/стейкинг](ABI-NFT-STAKING-AUDIT.md), [Safe/валидаторы](ABI-VALIDATORS-SAFE-AUDIT.md). Локальный fork отделен от публичной сети: [LOCAL-FORK-VALIDATION.md](LOCAL-FORK-VALIDATION.md).

Глобальное управление контрактами сети (ownership renounce/upgrade/системные награды), consensus node и подписи чужих администраторов не входят в обычный desktop-кошелек. Произвольный расширенный ContractCall не заменяет отдельную реализацию или проверку таких сценариев. В текущем mainnet NFT delegation-nft непосредственно подтверждена пауза; новый approval/делегирование останавливаются с понятным сообщением до подписи. Token/DEL delegation не приостановлен. Пауза mainnet NFT-делегирования и исключение моста являются принятыми границами релиза 0.2.0. Снятие внешней паузы требует нового сетевого прогона перед заявлением о доступности NFT-делегирования. Статус стабильного релиза не означает независимую сертификацию всех ABI/ролевых комбинаций.
