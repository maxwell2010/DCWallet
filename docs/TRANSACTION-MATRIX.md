## Limits and defects

- Catalog excludes builders returning SafeTransactionDraft. Safe typed hash/sign/pack/exec is tested separately, including chain/nonce binding and duplicate rejection. Safe deployment, threshold/nonce RPC and coordinated signing UI remain separate workflows.
- Checked mint/burn builders use a controlled RPC fixture with owner, mintable, burnable, cap and balance reads; actual deployed token execution remains unknown.
- TokenEconomyDrafts.BuildMintDraft is intentionally unsupported by the SDK: mint(address,uint256) is absent from DecimalToken ABI at go-smart-node 9e6c6d7. The fixture asserts rejection, not successful draft construction.
- Permit fixtures check calldata shape. Wallet does not create a real token permit in these tests.
- Bridge tests validate draft value and overflow. Relayer/VM finalization, cross-chain fees and destination execution remain unverified.
